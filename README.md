# FoodDK

منصة توصيل طعام للدنمارك، تربط الزبائن والمطاعم والسائقين.

## المراحل
1. **الأساس:** تسجيل دخول، المطاعم والقوائم، السلة، الطلبات، لوحة المطعم، لوحة السائق، تتبع الطلب.
2. **الدفع والتسعير:** Stripe Connect، حساب المسافات، الضريبة (moms 25%).
3. **الإطلاق:** اختبار أمني، GDPR، تطبيق موبايل.

## التشغيل المحلي
```
npm install
npm run dev
```

# FoodDK

منصة توصيل طعام للدنمارك، تربط الزبائن والمطاعم والسائقين.

## المرحلة الأولى (الحالية)
- تسجيل دخول وإنشاء حساب للزبائن
- قائمة المطاعم والقوائم والسلة
- إتمام الطلب مع حساب الأسعار على الخادم وفق الضريبة الدنماركية (moms 25%)
- لوحة المطعم: قبول الطلب، بدء التحضير، جاهز للاستلام
- لوحة السائق: استلام المهمة، الاستلام، التسليم
- تتبع حالة الطلب للزبون

**ملاحظة:** الدفع في هذه المرحلة تجريبي فقط. الدفع الحقيقي عبر Stripe في المرحلة الثانية.

## التقنيات
- Next.js (App Router) + TypeScript + Tailwind
- قاعدة بيانات SQLite عبر `node:sqlite` (محلياً، في مجلد `data/`)
- كلمات المرور مشفّرة بـ scrypt

## التشغيل المحلي
متطلبات: Node.js 22.13 أو أحدث.
```
npm install
npm run dev
```
افتح http://localhost:3000
